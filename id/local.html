Mendownload program IRTH

Beberapa pengguna meminta agar salinan lokal dari program IRTH tersedia sehingga mereka dapat menjalankan program ketika tidak ada koneksi internet yang tersedia. Ini adalah keuntungan yang jelas dari memiliki salinan lokal dari program tersebut. Kerugiannya adalah bahwa pengguna mungkin melewatkan pembaruan program di masa mendatang. Harap periksa secara berkala untuk melihat apakah tanggal pembaruan terakhir lebih lambat dari tanggal Anda mengunduh program.

Anda dipersilakan untuk menyalin dan mendistribusikan program ini kepada sebanyak mungkin orang jika Anda tidak memodifikasinya dan jika Anda memberikannya. Program IRTH memiliki hak cipta ©1989+ (CC-BY-NC-ND) dan tidak untuk dijual.

Tautan unduhan di bawah ini akan menempatkan file arsip Zip di penyimpanan perangkat Anda. Anda perlu mengekstrak file dari arsip ke folder pilihan Anda.

Untuk menjalankan program, cukup luncurkan file irth.html untuk menjalankan antarmuka klasik (pakar), atau file irthwiz.html untuk menjalankan antarmuka wizard.
